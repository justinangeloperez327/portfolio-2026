# Initial Case Studies

The portfolio now includes structured case-study content for:

- Berserk
- Gungnir
- Densleaf
- Quagmire

All studies use the shared case-study system and are statically generated from
the project registry.

## Editorial standard

These are engineering narratives, not promotional claims. Current project
status is stated directly, and experimental work is not presented as
production-proven.

Results describe current capabilities, architectural progress, and lessons
where measured production outcomes do not yet exist.

## Next iteration

Future project-specific blueprint work can attach request lifecycles, package
relationships, compiler stages, and runtime architecture to the relevant
sections using the software blueprint system.
