# Typography System

## Objective

Typography carries most of the portfolio's hierarchy. The system favors scale,
spacing, weight, and rhythm over decorative treatments.

## Components

### DisplayHeading

Reserved for primary page statements and major case-study moments. Normally
renders an `h1`; `h2` is available when document hierarchy requires it.

### SectionHeading

Used for major and secondary content sections with explicit semantic heading
selection.

### Eyebrow

Short uppercase contextual labels. Keep copy concise.

### Lede

Introductory prose with increased scale and line height.

### Prose

Long-form editorial and case-study content. Provides controlled paragraph,
heading, list, link, quote, and inline-code rhythm.

### TechnicalLabel

Compact monospace metadata for technical classifications, versions, statuses,
and diagram labels.

### EditorialAccent

A restrained serif treatment for occasional editorial contrast. It must not
replace the primary sans-serif hierarchy.

## Rules

1. Heading components do not infer semantic level from visual size.
2. One primary `h1` should identify each page.
3. Body text remains at least 16px.
4. Long-form text remains near the 72-character reading measure.
5. Uppercase labels use additional letter spacing and should remain short.
6. Serif styling is an accent, not the default body face.
7. Technical metadata uses monospace to distinguish it from narrative content.
8. Avoid artificial font-weight proliferation.
