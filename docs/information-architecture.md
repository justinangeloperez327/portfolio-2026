# Portfolio Information Architecture

## Primary routes

- `/` — introduction, positioning, selected work, engineering perspective
- `/work` — project index
- `/work/[slug]` — project case study
- `/engineering` — engineering notes and technical thinking
- `/about` — background and working principles
- `/resume` — professional experience and capabilities
- `/contact` — contact paths

## Project taxonomy

Projects are classified as Framework, Programming Language, Frontend, or Application.

## Case-study hierarchy

1. Context
2. Problem
3. Design Principles
4. Architecture
5. Implementation
6. Developer Experience
7. Engineering Decisions
8. Result

The structure is intentionally content-first. Visual composition and reusable
presentation components are introduced in later design-system groups.
