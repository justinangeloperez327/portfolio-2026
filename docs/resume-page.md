# Resume Page

## Purpose

The Resume page provides a concise professional overview while preserving a
strict boundary between verified career history and portfolio-derived
information.

## Current sections

1. Professional profile
2. Capabilities
3. Technologies
4. Current independent engineering work
5. Professional history placeholder

## Data integrity

Employment chronology, employer names, job titles, education, certifications,
and dates are intentionally not reconstructed from partial context.

Those details should be added only from a source resume or other verified
professional record.

## Presentation

The page uses the portfolio's editorial system instead of a conventional
two-column resume template. Print rules keep the layout usable when printed
while hiding the temporary professional-history notice.

## Future work

When verified resume data is available:

- create a typed resume data source;
- add chronological experience entries;
- add education and certifications where applicable;
- add a downloadable resume asset if desired;
- generate structured data from the same source to avoid duplicated facts.
