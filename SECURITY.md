# Security Policy

## Supported version

The current `main` branch is the supported version of this portfolio.

## Reporting a vulnerability

Do not publish a suspected vulnerability in a public issue if it could expose
users, credentials, deployment infrastructure, or private data.

Report security concerns privately to:

**justinangeloperez327@gmail.com**

Include the affected route or component, reproduction steps, expected impact,
and any relevant browser or environment information. Do not include secrets,
access tokens, or unrelated personal data in the report.

## Scope

This repository is a public portfolio. It currently has no authentication,
payments, user accounts, database-backed contact form, or intentional storage of
visitor-submitted personal information.

Dependencies and deployment infrastructure remain part of the security surface
and should be kept patched.
